# 🏙️ Smart City Command Center

A modern smart city dashboard built using **HTML, CSS, JavaScript, and Vite**.  
It displays real-time city information such as weather, exchange rates, citizen profile data, city facts, and includes an AI-powered smart assistant.

## 🚀 Features

- 🌦️ Real-time weather information
- 💱 INR exchange rate conversion
- 👤 Featured citizen profile
- 💡 Random city fact of the day
- 🤖 AI smart assistant using OpenRouter API
- 🎨 Modern glassmorphism UI
- 📱 Responsive layout
- ⚡ Fast development setup with Vite

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite
- OpenRouter API
- Open-Meteo API
- Exchange Rate API
- Reqres API
- Random Facts API
